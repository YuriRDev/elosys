## Why

O usuário quer consultar o Elosys a partir de scripts com contratos documentados, em vez de depender dos detalhes internos da interface.

## What Changes

Definir API versionada de leitura com busca, entidades, finanças e proveniência, parâmetros validados e exemplos reprodutíveis.

## Capabilities

### New Capabilities
- `public-query-api`: API de consulta documentada.

### Modified Capabilities
Nenhuma spec canônica existente.

## Impact

Rotas versionadas e documentação de contratos; reutiliza consultas existentes. Não inclui hospedagem pública, cadastro ou operações de escrita.
